<h2>Introduction</h2>

본 문서는 개발하고자 하는 1인칭 공포 생존 싱글플레이 게임인 'Area Keeper'의 Software Design Specification(SDS)이다.<br/>
<br/>
문서에서는 'Area Keeper' 게임 개발에 필요한 기능적 요구사항들을 구현하기 위한 소프트웨어 설계를 상세히 기술한다.<br/> 사용자 관점, 시스템 구조적 관점, 시스템 동적 관점에서 게임 시스템을 설계하여 개발팀에게 명확한 지침을 제공하는 것을 목표로 한다.<br/>
본 문서에서는 다음과 같은 내용을 다룬다.
* Use Case Analysis: 사용자(플레이어) 관점에서 게임이 제공하는 기능들을 분석하고 명세한다.
* Class Diagram: 게임 소프트웨어의 정적 구조와 클래스 간의 관계를 정의한다.
* Sequence Diagram & State Machine Diagram: 게임 시스템 내 객체 간의 상호작용과 상태 변화 등 동적 흐름을 묘사한다.
* User Interface Prototype: 플레이어가 상호작용하게 될 UI 요소들을 설계한다.
 
본 문서 작성 시 가장 중요하게 고려한 점은 각 설계 다이어그램 간의 일관성을 유지하는 것이다.<br/> 
또한, 이상 현상의 식별 및 처리(도구 사용 및 소지), 제한 시간, 이상 현상 미해결 시 누적되는 패널티 시스템 등 게임의 핵심 메커니즘들이 설계에 정확히 반영되도록 주의하였다.
