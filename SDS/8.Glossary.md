# 8. Glossary

**Enum (열거형)**

3 장의 Class Diagram 에는 사용되었지만 클래스 목차에 기술되지 않은 열거형에 대해 이 장에서 기술한다.

| 이름 | 설명 |
|---|---|
| EAnomalyCategory | '소지' UI에서 사용되는 이상현상의 범주를 정의하는 열거형. (예: AC_Visual, AC_Auditory, AC_Object, AC_Environmental) |
| EAnomalyType | '정지형 이상현상'이 미해결되었을 때의 결과를 정의하는 열거형. AT_Disappearing (사라지며 패널티 스택 증가)과 AT_Chasing (추적형 이상현상 스폰)으로 나뉜다. |
| EAreaKeeperPlayState | AAreaKeeperGameState가 관리하는 게임의 현재 상태를 나타내는 열거형. EPS_WaitingToStart (준비 구역 대기), EPS_InProgress (게임 진행 중), EPS_GameFinished (게임 종료)로 나뉜다. |
